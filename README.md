# SunLicense Scoop bucket

```powershell
scoop bucket add sunlicense https://github.com/sunlicense-com/scoop-bucket
scoop install sunlicense/sunlicense
```

Updated automatically with every release of the [sunlicense CLI](https://docs.sunlicense.com/cli/). Upgrade with
`scoop update sunlicense`. Problems: https://sunlicense.com/contact
